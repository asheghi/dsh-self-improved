# Sessions continuity takeover

`src/continuity-sessions-v03.ts` provides the coordinator-facing, read-only Sessions view/business adapter. It filters explicit source candidates to the target project, exposes unfinished-work metadata without reading protected notes, and reports a concrete Continue availability reason. Continue requires a Host-authenticated intent callback, explicit source selection, same-project native source observations, and an existing completed handoff identity before delegating to the v3 preview owner.

The adapter performs no DDL, writes, prompt dispatch, native event invention, or mutation. Every native observation is a caller-owned disposable lease and is released on success, failure, cancellation, and partial acquisition. Candidate output is bounded, sanitized, and detached; protected note payloads are never read. With no authenticated Host intent hook it fails closed in both view and continue, with an explicit availability reason. Source identity, project, and unfinished-work checks reject aliases, forged ids, cross-project sources, and untrusted lineage. UI wiring remains with the coordinator through `ContinuitySessionsOrchestratorV03`.
