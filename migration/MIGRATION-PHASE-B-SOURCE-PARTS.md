## Implementation

Default callers and tool/assistant producers retain the earlier typed atomic overflow rejection; previous refusal gates are intentionally unchanged.

Redaction runs on the complete event BEFORE splitting, preventing secrets spanning persistence boundaries from escaping minimization. Root source text contains the first bounded part; additive `journal_source_parts` holds the remainder, each part at most `sourceMaxChars`. The original native `(session_id, seq)` remains the sole source coordinate. The complete minimized text length and event hash stay on its root. Header, root, parts, planned chunks and job enqueue commit in the same transaction. Immutable re-flush hashes deduplicate the complete content.

Evidence integrity and deterministic worker segmentation reconstruct all minimized parts transiently. Complete-event hash/length checks run before evidence delivery and again inside candidate commit. Missing or modified overflow fails closed. Consumption uses the complete segment count and stays false until the final acknowledgment. Existing sources require no rewrite; no parts means the original representation.
