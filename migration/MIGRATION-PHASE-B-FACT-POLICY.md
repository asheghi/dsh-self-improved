# Fact-scoped shared mutation policy

The shared business policy now passes mutated memory IDs to the journal's authoritative derivation ledger. It no longer revokes an entire session for an individual fact. Supporting chunk coordinates are spent; intersecting queued/claimed jobs become terminal with cleared claim tokens. Sessions, unrelated pending/future events, sibling memory statuses and the global consent generation remain unchanged.

Forget, direct correction and confirmation run their memory mutation and journal support revocation on MemoryStore's same SQLite transaction. A journal fault rolls back both the human decision and support flags, including revision increments and candidate inserts. Missing ownership for a journal-bound derived mutation refuses rather than logging uncovered success.

Independent evidence: bash-2414 full strict rc.2 compilation and initial shared-policy checks passed. Final [fact-policy suite](<../scripts/test-v02-fact-policy.mjs>) passes eight real-SQLite checks (latest full strict build bash-2417), including an initially failing late-response reproduction now fenced at the final transaction: forget preserves unrelated same-session claims/future evidence, human correction remains authoritative, forget/correct/confirm failures roll back, confirmation spends the old support, and missing ownership fails closed. [Lifecycle suite](<../scripts/test-v02-journal-worker-review.mjs>) passes fourteen checks including genuine reopen and in-flight partial-chunk revocation. git diff --check passed.

Limits: revocation is conservative at supporting-chunk/event granularity, not individual words within an event. The old native policy fixture asserts whole-session tombstones and global generation bumps for fact mutations; its prior 35-pass result belongs to the previous policy, not this checkpoint. Its unit callbacks and NativeLoader/Gateway/tool assertions have been strengthened to this narrower contract, including actual unrelated pending/future provider/consumption controls; bash-2418 passed all thirty-five native policy gates, including real Node pending timers and Gateway/command/tool mutations. This does not accept all Phase B gates. Final commit also refuses same-scope/kind bodies matching forgotten/corrected records, ignoring case and outer whitespace. This is not semantic paraphrase suppression and is not advertised as such. Oversize canonical recovery and native runtime pending-kick promotion also remain open.
