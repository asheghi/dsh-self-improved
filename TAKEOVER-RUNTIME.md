# v3 runtime takeover

`ContinuityRuntimeV03` is deny-by-default and accepts only an owner-admitted, one-time receipt. Receipt admission is bounded; once the bounded receipt capacity is full, new receipts are denied rather than evicting history. The runtime checks the durable summary policy before capture and again before provider work and completion.

Claims now select only the exact captured job ID on the same SQLite writer; an older same-project job cannot borrow the triggering session's reader or acquire a lease accidentally. Before the summarizer is called, `ContinuityWorkV03.isCurrentWithFreshSource` rechecks the exact policy/lease/anchors and full native lineage/source. Completion independently repeats that proof. A separate explicit live `canSummarize` callback defaults to denial; both it and the durable summary epoch gate pre-egress and late completion. The runtime passes its owned abort signal to the summarizer. Neither source kinds nor receipt DTOs authenticate a Host event; the trusted injected admission callback remains responsible for actual Host authority.

All overlapping invocations are tracked. A new invocation aborts prior invocations, and `dispose()` aborts and awaits every tracked promise with `Promise.allSettled`, including noncooperative older jobs. Accepted-job capacity is bounded and denies when full; unrelated oldest claims are not silently substituted.

The coordinator replaced the initial misleading test (whose purported happy path allowed denial) with a genuine private native Session/SQLite pipeline. `scripts/test-v02-continuity-runtime-v03.mjs` now passes 7 gates: default/forged admission denial, absent consent/preabort, exact completed handoff plus receipt replay refusal, older foreign-session job unleased, pre-egress native source drift refusal, held-provider epoch revocation, and disposal draining both overlapping noncooperative providers. Strict rc.2 build/emit passed; independent Luna source/test review found no material defect within this unmounted runtime scope. Run only with explicit `DSH_RUNTIME_RC2` and fresh emitted `lib`. Authenticated Host ingress, main-plugin mount, actual provider minimization, browser Continue, and full task-summary completeness remain open; the callbacks in this fixture are synthetic.
