## Behavior and source boundary

Default live provider/body consent is denied. Exact current claim admission is rechecked before async observation, after observation, immediately before streaming, on each returned chunk, after stream, and within the FINAL SAME MemoryStore IMMEDIATE transaction containing nested handoff commit. This last writer lock prevents another SQLite connection from substituting original verified source anchors between admission and commit. Cancellation/disposal owns an AbortController shared with observation and provider. Acquired native lease is disposed in finally on success/refusal/malformed/error/cancellation; timer and external-signal subscription are always removed. Noncooperative awaited work retains ownership until actual settlement; caller must not close MemoryStore early.

Historical source validation uses the current source primitive: full contiguous native observation, exact original historical cut, composite immutable header/fork-floor/event fingerprint, nondelegated native project/session ownership, actual native cold projection restore, and own-human authority. Only latest OWN append user-message text with kind=user can become excerpts. Assistant/tool bodies, attachments, inherited events, injected/coordinator/tool-source user-role messages are omitted. Shared paste heuristic and explicit Markdown-blockquote refusal reject obvious paste/quotation, including any message longer4000chars. Redaction runs over each whole eligible event BEFORE clipping.

Provider input is ALWAYS partial/unverified: up to8 eligible excerpts, at most1500chars each and6000total excerpt chars; JSON input+system instructions must fit12000chars. Token request max768, temperature0. Output at most3000text chars/2048chunks; only stop completion and text output accepted. Strict output is `{excerpts:[{seq,quote}]}` with at most3 nonblank quotes of at most200chars. Each quote must be an exact substring of the minimized excerpt actually sent for its exact seq, with duplicate selections refused. Stored notes are deterministic `Partial unverified excerpt [seq N]: ...`, at most280chars, under existing constant uncertain=true. Provider cannot supply prose task-success, arbitrary anchors, permission fields or resumed actions. Empty valid selection is a distinct completed empty handoff, not malformed output.

It never replaces native history and does not certify completion or external effects. It omits assistant/tool/structural-goal content; unfinished-work structural projection remains separately authoritative. This increment bounds plugin provider input/output, not native transcript memory or provider infrastructure cost. Character caps and maxTokens are not exact tokenizer/cost accounting.
