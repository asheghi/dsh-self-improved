## C implications and conservative path

[Shared capture helper](<src/capture.ts#L439-L448>) rejects every nonempty parentSession. [C version1 fold](<src/continuity-projection-v02.ts#L39-L63>) consequently marks ordinary forks delegated forever and suppresses owned user coordinates, even after new own events. Removing only the parent fallback fixes that false structural classification but cannot establish human authority by itself.

Separate structural product classification from durable admission. A C-only classifier may identify explicit origin/depth subagents, while a trusted async admission owner resolves canonical ancestry/creation evidence outside the pure projection. Preserve actual inherited floor and require fresh OWN user intent; copied parent user events, inherited tool effects and child synthetic fork closers never establish human intent or verified task success. Missing/cyclic/inconsistent ancestry, contradictory markers, inaccessible source or unknown producer stays denied; catalog absence is not an allow. If the implementation elects a narrower trusted-native-producer threat boundary, document it explicitly rather than calling absent markers a universal direct-human guarantee.

Changing init/apply delegation semantics requires a new CONTINUITY_STATE_VERSION and registry stateVersion, because [registry schema](<src/continuity-registry-v02.ts#L41-L67>) and SDK persisted cache encode delegated/lastHumanSeq. [Cold recovery](<src/continuity-checkpoint-v02.ts#L50-L79>) already compares row.ver and rederives canonical prefix: reject old-state cached rows and full-refold, never flip a persisted delegated flag in place. Existing composite sourceHash binds CHILD header/floor/events, not ancestor headers or admission proof. A future ancestry-dependent authority receipt needs its own explicit binding/revalidation/revocation design; old pending jobs must not silently acquire expanded permissions.

Required future gates: genuine ordinary native fork before/after fresh own user; direct seeded and unseeded subagents; fork-of-subagent and deeper ancestry; absent/corrupt/cyclic ancestor refusal; old-version cache cold refold; same canonical source cut and policy/lease fences; no shared A/B behavior change. These are recommendations, not executed acceptance evidence. Phase C remains OPEN.
